# 💡 SIPPAT - Visão Geral e Propósito

## Contexto
O Posto de Atendimento ao Trabalhador (PAT) de Jacareí/SP lida diariamente com encaminhamento para vagas, atualização cadastral e mapeamento de vulnerabilidade. O processo manual atual em planilhas gera lentidão, retrabalho e risco de perda de dados.

## Objetivo do SIPPAT
Desenvolver um sistema web interno moderno, rápido e inteligente para os funcionários do PAT Jacareí, centralizando o registro de cidadãos, perfil profissional, indicadores socioeconômicos e busca avançada com filtros combinados.

> **Nota:** o cálculo automático de pontuação de vulnerabilidade para ordenar a busca por prioridade social foi **removido do escopo atual** por decisão em reunião (ver `questions.md` #5-7). Os indicadores socioeconômicos continuam sendo capturados (RF-003); apenas o algoritmo de priorização automática fica para uma fase futura.

## Usuários-Alvo
- Funcionários e Atendentes do PAT Jacareí.
- Administradores do sistema / Gestores do projeto de extensão do IFSP Câmpus Jacareí.
